# Sweet Crumbs — build the APK without Android Studio

1. Create a GitHub repository.
2. Upload the contents of this `SweetCrumbs` folder to the repository's `main` branch.
3. Open **Actions** and select **Build Sweet Crumbs APK**.
4. Press **Run workflow** if it did not start automatically.
5. When it finishes, open the workflow run and scroll to **Artifacts**.
6. Download **SweetCrumbs-debug-apk** and unzip it on your Android phone.
7. Tap `app-debug.apk` to install it. Android may ask you to allow installation from that source.

This workflow builds a debug APK on GitHub's servers; Android Studio is not required.
