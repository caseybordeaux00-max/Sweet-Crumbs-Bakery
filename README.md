# Sweet Crumbs — Android cake-shop game prototype

This is an Android Studio project for a hands-on cake-shop game. The visual direction is based on the Sweet Crumbs concept image included at `app/src/main/res/drawable/concept_reference.png`.

## Gameplay slice
1. Customer gives a cake order.
2. Bake two chocolate layers.
3. Assemble them.
4. Swipe to frost.
5. Drag/tap strawberries onto the cake.
6. Draw cuts to make eight slices.
7. Serve and receive a customer reaction/tip.

The game is implemented as a custom Android View so the cake/workspace can respond directly to touch rather than relying on a button-driven web mockup.

Open the folder in Android Studio and build the `app` module to create the APK.
